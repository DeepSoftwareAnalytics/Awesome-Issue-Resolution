# Images

This directory contains images used in the documentation.

## Files

- `awesome-issue-resolution.png` - Main hero image for the website
- `framework.png` - Framework overview diagram
- `favicon.png` - Website favicon (should be created from awesome-issue-resolution.png)

## Creating Favicon

To create the favicon from the main image:

1. Use an online tool like [favicon.io](https://favicon.io/) or [realfavicongenerator.net](https://realfavicongenerator.net/)
2. Upload `awesome-issue-resolution.png`
3. Generate a 32x32 or 64x64 PNG favicon
4. Save as `favicon.png` in this directory

Alternatively, you can use the same `awesome-issue-resolution.png` as the favicon temporarily.
